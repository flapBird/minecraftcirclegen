# Minecraft block texture assets

These textures were extracted from Minecraft: Java Edition 26.1.2 and downloaded
from the [InventivetalentDev Minecraft assets mirror](https://github.com/InventivetalentDev/minecraft-assets/tree/26.1.2/assets/minecraft/textures/block).
The shelf textures not yet present in that mirror came from Palettinator's
public texture directory. They are used only to identify the corresponding
blocks in this fan-made Minecraft building tool.
